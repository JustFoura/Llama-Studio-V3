How to run

Double-click start.cmd (or run npm start in the gui folder). Pick a model, set the address, click Start Server, then chat on the Playground tab or from your phone at the API address.

Where do my models go?

Put every *.gguf model and *.mmproj vision encoder in the Models folder shown under Model. The app points there automatically and lists what it finds.

MTP (Multi-Token Prediction)

Faster generation using the MTP head built into the model (e.g. unsloth/*-MTP-GGUF). Enable MTP to run --spec-type draft-mtp --spec-draft-n-max N. If your model ships the MTP head as a separate file, set MTP model file and the app adds --spec-draft-model <file>. Incompatible with mmproj and parallel > 1.

DFlash (speculative decoding)

Block-diffusion speculative decoding with a separate DFlash draft model. Attach a DFlash GGUF (e.g. Qwen3-4B-DFlash.gguf) and enable DFlash to run --spec-type draft-dflash --spec-draft-model <file> --spec-draft-n-max N. DFlash is mutually exclusive with MTP and incompatible with mmproj.

Recommended defaults

Hover any ? for an explanation. The pre-filled values (temp 1.0, top-k 40, repeat penalty 1.1, context 8192, GPU layers 99, flash attention on) work well for most models. Click Reset all to recommended defaults anytime.

Presets

Type a name, click Save as preset to snapshot all settings (model paths, image settings, address, sampling). Load restores one. Presets are stored in presets.json next to the app.

Switch models from your phone

When the API address is set to a LAN/VPN interface, open that same address on your phone. You'll see every preset and model in your Models folder. Tap one to stop the server and reload it with those settings. The default localhost address is only reachable from this computer.
